Free and open source · macOS 14 or later

Music, files, clipboard and a terminal, one hover from your notch.

DropNotch turns the MacBook notch into a productivity surface. It opens when you hover over it or press ⌃⌥N, and stays out of the way otherwise.

Questions

Is it free?

Yes. DropNotch is free and open source under the MIT licence. There's no account to create.

Why does macOS block it the first time?

DropNotch isn't signed with an Apple Developer ID or notarised yet, so macOS says "DropNotch.app" Not Opened. Click Done, then open System Settings › Privacy & Security and click Open Anyway. Signed builds are planned for 1.0.

Which Macs does it work on?

macOS 14 Sonoma or later. It's built for MacBooks with a notch; other Macs get a compact pill at the top of the screen. It has only been tested on Apple silicon.

What does it send off my Mac?

No analytics, no accounts, no telemetry. The only network request fetches Spotify artwork over HTTPS from i.scdn.co, and you can turn that off in Settings › Privacy.

What permissions does it ask for?

Only when you first use the feature that needs it, never at launch: Automation the first time you use a Music or Spotify control, Calendars when you turn on the Calendar card, and folder access when the tray first opens a file from Desktop, Documents or Downloads.

Which music apps does it support?

Apple Music and Spotify. Other players aren't supported yet.

Is the terminal safe to leave on?

It's off until you turn it on. Commands you run there use DropNotch's permissions, as they would in the terminal inside VS Code or iTerm. Settings shows exactly what that includes before you turn it on.

How do I update or uninstall it?

There are no automatic updates yet. Run brew upgrade --cask dropnotch, or download the new version here. To uninstall, quit from the menu-bar item and move DropNotch to the Bin, or run brew uninstall --cask dropnotch.

Install

Download

  1. Open the DMG and drag DropNotch into Applications.
  2. Open DropNotch. When macOS says it's Not Opened, click Done.
  3. In System Settings › Privacy & Security, click Open Anyway, then Open.
Download DropNotch 0.2.0

Check the download with the SHA-256 file. All versions are on GitHub Releases.

Homebrew

brew install --cask shashwat-19/tap/dropnotch

This adds the tap and installs in one step. The first launch still needs Open Anyway, as with the DMG. Later, brew upgrade --cask dropnotch updates it.

Tried it? Tell me what's missing.

Bugs, feature requests and "I uninstalled it because…" all help. It takes a GitHub account.
